# roboops-so101

RobOps検証：SO-101実機のROS2化と2カメラ（front + wrist）運用。個人学習用（松尾研Physical AI応用編とは別立て。応用編で使う名前空間を空けるため so101 名を避けている）。

## このリポジトリの位置づけ
- **状態の正本**。作業の発注・進行・報告はすべてここに置く。チャット側Claude（玉配）とUbuntu機のClaude Codeセッションは、口頭連絡でなくこのリポジトリを介して連携する。
- 発注は `QUEUE.md`、報告は `REPORTS/`、環境の確定事項は `ENV.md`（玉1が作成）、カメラ運用値は `CAMERA.md`（玉3が作成）、旧構成の凍結記録は `legacy/`（玉2が作成）。
- ROS2化の机上評価は `ROS2_EVAL.md`（chat担当）。

## 大方針（2026-08-30時点の合意）
1. **自作より既製品**：ROS2スタックは既製（本命 legalaspro/so101-ros-physical-ai）を選定評価して使う。ドライバや変換器を自作しない。
2. **動態保存**：現行のlerobot直結ライン（/home/masayuki/so101、lerobot 0.4.4 venv）は、ROS2経路が同等性試験に合格するまで殺さない。切替は明示的に行う。
3. **段階導入**：環境同定 → 現行構成の正本化 → カメラ2台の前倒し検証 → ROS2スタック導入（乾式→実機）→ 同等性試験 → 切替。
